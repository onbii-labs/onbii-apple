# OnbiiMac

The Milestone 1 macOS producer app is not scaffolded yet.

Its agreed initial direction is documented in
[`docs/architecture/macos-capture-import-direction.md`](../../docs/architecture/macos-capture-import-direction.md).

The first vertical slice imports an existing audio file into a user-selected
archive through `OnbiiArchive`. Explicit live capture follows as a separate
capture-adapter path.
