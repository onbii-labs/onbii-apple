# Security Policy

## Reporting a Security Vulnerability

Onbii Apple may handle sensitive personal knowledge, including recordings, transcripts, metadata, locations, and derived artefacts.

Please report security or privacy issues privately rather than opening a public GitHub issue.

You can contact the maintainers by opening a GitHub Private Vulnerability Report if enabled, or by using the project's published security contact details.

Please include:

- a description of the issue;
- the affected component;
- steps to reproduce, where applicable;
- the potential security or privacy impact;
- any suggested mitigation.

## Responsible Disclosure

Please do not publicly disclose security vulnerabilities until the maintainers have had a reasonable opportunity to investigate and, where appropriate, address the issue.

We appreciate responsible disclosure and will acknowledge valid reports.

## Supported Versions

This repository is pre-release. Until stable releases exist, the latest `main` branch should be considered the only supported development version unless stated otherwise.

## Sensitive Areas

Please take particular care with changes involving:

- microphone or system audio capture;
- local files and archive locations;
- iCloud or other sync-backed storage;
- Watch-to-iPhone or device-to-device transfer;
- transcription and processing providers;
- location metadata;
- logs, diagnostics, and crash reports;
- preservation of original source material.
