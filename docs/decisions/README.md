# Decisions

Apple-implementation decision records for `onbii-apple`.

These preserve the reasoning behind Apple-specific choices that future
contributors are likely to question. Shared product and format decisions live in
the spec's own decision log
([`docs/spec/docs/decisions`](../spec/docs/decisions)); records here are scoped to
this repository's implementation.

## Index

| ID | Decision | Status |
| --- | --- | --- |
| [0001](0001-apple-capture-audio-format.md) | Capture audio as AAC on every Apple platform | Accepted |

## Status Values

- **Accepted**: the current implementation direction.
- **Tentative**: likely direction, but still open to revision.
- **Superseded**: replaced by a later decision.
- **Rejected**: considered and explicitly not chosen.

## Format

Records should include status, date, context, decision, and consequences, and
stay short enough to read quickly.
