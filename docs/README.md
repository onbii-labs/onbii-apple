# Onbii Apple Docs

This directory contains Apple implementation direction.

The shared Onbii specification lives in [`spec`](spec). Apple-specific architecture, milestone planning, app target decisions, entitlements, and implementation notes should live here rather than in the spec repository.

- [`architecture`](architecture) — implementation direction and its open questions.
- [`milestones`](milestones) — what each milestone scoped and delivered.
- [`field-tests`](field-tests) — what real use away from a development machine revealed.

Numbered decision records (ADRs) are logged in the spec's own decision log at [`spec/docs/decisions`](spec/docs/decisions).
